# Habits

Open **Utilities > Habits**, choose **New habit**, and enter a name, optional cue, icon, and weekdays. Select at least one weekday, then save.

Use **Check in** for today or a scheduled date in the seven-day trail. Use **Undo** or tap a completed date to reverse it. Check-ins stay in place while saving; **Saving…** identifies the affected control. A failed save preserves the last saved state and entered values.

Each saved check-in earns 10 XP once. Levels advance every 100 XP. Milestones come from actual history: first check-in, 10 check-ins, a seven-check-in streak on one habit, and 50 check-ins. Undo recalculates rewards.

Rest days do not break a streak. An unfinished today allows you to continue the previous streak; a missed scheduled day can reset it. Schedule changes start today and preserve earlier schedules. Future, pre-creation, and unscheduled dates cannot receive new check-ins.

Archive retains history and XP and pauses check-ins; **Archived habits > Restore** enables them again. Habit data belongs to the signed-in account. Legacy tasks with habit labels are separate and are not automatically imported.

On compact screens, editing uses a native dialog with scrolling fields and a separate save footer. The history trail scrolls horizontally when needed, and Milestones starts collapsed. Entered values survive compact orientation changes, and closing returns focus to the invoking control.
