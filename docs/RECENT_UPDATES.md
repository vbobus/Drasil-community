# Recent updates

October 2026 Community refresh.

- **Weekly planning:** continuous day scrolling, task trees, actionable subtasks, per-day progress, and independent tree/calendar panels. Work planned for a later day stays visible without blocking today's completion.
- **Day moves:** calendar and planned-day assignments move together while retaining task identity, time, duration, recurrence overrides, and other-day plans. Untimed moves do not create extra bookings.
- **Day removal:** remove a selected day's plan and bookings with confirmation; keep the tree task and plans on other dates.
- **Habits:** weekday schedules, check-ins and undo, seven-day history, streaks, XP, levels, milestones, archive, and restore.
- **Mobile:** labeled navigation, full-width working surfaces, native chat/editor dialogs, larger touch controls, and smooth viewport/resize updates.
- **Conversation and review:** floating chat, retained drafts, structured before/after review, explicit apply/revise/reject, and clear save/recovery states.
- **Loading:** an authenticated workspace bootstrap, shared calendar ranges, account-scoped reload snapshots, background refresh, and visible retry states. Chat and administrative surfaces load on demand.
- **Hosting:** PostgreSQL storage, account-isolated credentials, Vercel build configuration, and a public setup guide alongside Docker/VPS deployment.

These are shipped interface and source capabilities, not performance guarantees. The [showcase](SHOWCASE.md) records the current UI with mocked responses; it does not demonstrate a live model or third-party sync. Personal incident records, account repairs, and private deployment histories are not included.
